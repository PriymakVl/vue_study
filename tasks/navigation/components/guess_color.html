Угадай цвет — Vue Task

Задание

  1. Создать игру «Угадай цвет», генерирующую случайно выбранный RGB-цвет и набор цветных блоков.
  2. При клике на блок проверять соответствие выбранного цвета загаданному и выводить результат (правильно/неверно).
  3. Реализовать перезапуск игры с генерацией новой комбинации цветов при нажатии на кнопку «Новая игра».
Демо

Решение задачи (Компоненты Vue)

App.vue

Главный компонент управления состоянием игры, генерации цветов и обработки ответов

<template>
  <div id="game-app">
    <h2>Угадай цвет: <strong>{{ targetColor }}</strong></h2>

    <div class="color-boxes">
      <ColorBox
        v-for="(color, index) in colors"
        :key="index"
        :color="color"
        @select="guess(index)"
      />
    </div>

    <div class="result">{{ message }}</div>
    <button @click="startGame">Новая игра</button>
  </div>
</template>

<script>
import ColorBox from './components/ColorBox.vue';

export default {
  name: 'App',
  components: {
    ColorBox
  },
  data() {
    return {
      colors: [],
      correctIndex: null,
      targetColor: '',
      message: ''
    };
  },
  methods: {
    getRandomColor() {
      const r = Math.floor(Math.random() * 256);
      const g = Math.floor(Math.random() * 256);
      const b = Math.floor(Math.random() * 256);
      return `rgb(${r}, ${g}, ${b})`;
    },
    startGame() {
      this.colors = [];
      for (let i = 0; i = 4; i++) {
        this.colors.push(this.getRandomColor());
      }
      this.correctIndex = Math.floor(Math.random() * 4);
      this.targetColor = this.colors[this.correctIndex];
      this.message = '';
    },
    guess(index) {
      if (index === this.correctIndex) {
        this.message = '✅ Правильно!';
      } else {
        this.message = '❌ Неверно. Попробуй ещё.';
      }
    }
  },
  mounted() {
    this.startGame();
  }
};
</script>

components/ColorBox.vue

Дочерний компонент для отрисовки каждого цветного блока и генерации события выборки

<template>
  <div
    class="box"
    :style="{ backgroundColor: color }"
    @click="$emit('select')"
  ></div>
</template>

<script>
export default {
  name: 'ColorBox',
  props: {
    color: {
      type: String,
      required: true
    }
  },
  emits: ['select']
};
</script>
