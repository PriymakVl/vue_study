Dynamic Shapes — Vue Task

Задание

  1. Создать область для отображения геометрической фигуры и блок кнопок управления («Квадрат», «Круг», «Прямоугольник»).
  2. При клике на соответствующую кнопку изменять форму и цвет фигуры (квадрат — синий, круг — зеленый, прямоугольник — оранжевый).
  3. Выделять активную кнопку красным цветом текста, сбрасывая цвет остальных кнопок на стандартный.

Решение задачи

main.js

Инициализация Vue 3 и методы для динамической смены классов и стилей кнопок

const app = Vue.createApp({
  methods: {
    activeButton(event) {
      document.querySelectorAll('button').forEach(btn => btn.style.color = 'black');
      event.target.style.color = 'red';
    },
    setShape(shape) {
      let figure = document.querySelector(".figure");

      figure.classList.remove("square", "circle", "rectangle");
      figure.classList.add(shape);
    },
  },
});

app.mount("#app");
