Vue.js - Options API vs Composition API
2

Сравнение: Options API (data) vs Composition API (setup)

Критерий Options API (data()) Composition API (ref / setup)
Объявление Автоматически через объект data() Явно через ref() или reactive()
Организация кода По опциям (data, methods, computed) По логическим фичам и задачам
Переиспользование Сложно (через mixins) Легко (через composable-функции)
Когда использовать Небольшие компоненты, простые формы Масштабные проекты, TypeScript, гибкая логика
Options API
export default {
  data() {
    return {
      count: 0 // Реактивно автоматически
    }
  },
  methods: {
    increment() {
      this.count++;
    }
  }
}
Composition API
import { ref } from 'vue';

export default {
  setup() {
    const count = ref(0); // Явное ref
    const increment = () => count.value++;

    return { count, increment };
  }
}
