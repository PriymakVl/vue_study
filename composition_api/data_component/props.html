Vue.js — Props (`script setup`)
1

Передача данных от родителя к дочернему компоненту

В синтаксисе <script setup> родительский компонент передает данные через атрибуты с директивой v-bind (или сокращение :).

Передача данных из родительского компонента:

<!-- ParentComponent.vue -->
<template>
  <ChildComponent :title="postTitle" />
</template>

<script setup>
import { ref } from 'vue';
import ChildComponent from './ChildComponent.vue';

const postTitle = ref('Заголовок статьи');
</script>
2

Приём props через defineProps()

Для объявления пропсов в <script setup> используется макрос defineProps(), который не требует дополнительного импорта. 

<!-- ChildComponent.vue -->
<template>
  <h1>{{ title }}</h1>
</template>

<script setup>
defineProps({
  title: {
    type: String,
    required: true
  }
});
</script>
3

Параметры валидации props

  • 1
    type — определяет тип данных, который ожидает компонент (например, String, Number, Boolean, Array, Object).
  • 2
    required: true — указывает, что prop является обязательным для передачи из родительского компонента.
