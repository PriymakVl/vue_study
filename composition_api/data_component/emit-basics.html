Vue.js — Emit (`script setup`)
1

Объявление и генерация событий через defineEmits()

  • В синтаксисе <script setup> для отправки событий от дочернего компонента к родительскому используется макрос defineEmits(), который не требует импорта.
  • В шаблоне для быстрой отправки события также можно использовать встроенный метод $emit.

Отправка события из дочернего компонента:

<!-- ChildComponent.vue -->
<template>
  <!-- Отправка напрямую из шаблона -->
  <button @click="$emit('increment')">+1</button>

  <!-- Отправка через функцию в script setup с передачей данных -->
  <button @click="submitForm">Отправить данные</button>
</template>

<script setup>
// Объявляем список событий
const emit = defineEmits(['increment', 'submit']);

const submitForm = () => {
  // Вызываем событие и передаём полезную нагрузку (payload)
  emit('submit', { id: 1, text: 'Новое сообщение' });
};
</script>

Прослушивание событий в родительском компоненте

  • Родительский компонент подписывается на события дочернего компонента с помощью директивы v-on (или сокращения @).
  • Переданные из дочернего компонента аргументы автоматически попадают в функцию-обработчик. 
<!-- ParentComponent.vue -->
<template>
  <p>Счётчик: {{ count }}</p>
  <ChildComponent
    @increment="count++"
    @submit="handleFormSubmit"
  />
</template>

<script setup>
import { ref } from 'vue';
import ChildComponent from './ChildComponent.vue';

const count = ref(0);

const handleFormSubmit = (payload) => {
  console.log('Получены данные из дочернего компонента:', payload);
};
</script>
