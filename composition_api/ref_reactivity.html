Vue.js Composition API — Реактивные переменные с ref()
1

Создание и использование реактивной переменной

  • Для создания реактивных данных в Composition API используется функция ref().
  • Она принимает исходное значение (примитив или объект).
  • Оборачивает его в специальный реактивный объект RefImpl с единственным свойством .value. 
<!-- CounterComponent.vue -->
<template>
  <div class="p-4">
    <!-- В шаблоне .value писать НЕ нужно -->
    <p>Счетчик: {{ count }}</p>
    <p>Статический текст: {{ staticText }}</p>
    <button @click="increment">Увеличить</button>
  </div>
</template>

<script>
import { ref } from 'vue';

export default {
  name: 'CounterComponent',
  setup() {
    // 1. Создание реактивной переменной (оборачивается в объект со свойством .value)
    const count = ref(0);

    // 2. Обычная переменная (НЕ реактивная)
    const staticText = 'Это значение не изменится';

    // 3. Чтение и изменение значения в JS происходит через .value
    const increment = () => {
      console.log('Текущее значение:', count.value);
      count.value++; // Реактивное изменение обновляет интерфейс
    };

    // Передача переменных и методов в шаблон
    return {
      count,
      staticText,
      increment
    };
  }
}
</script>

Как работать с реактивной переменной ref():

  • import { ref } from 'vue' — обязательный импорт функции перед созданием реактивных переменных.
  • Обращение через .value в JavaScript: Чтобы прочитать или изменить значение count внутри скрипта (например, в функции increment), необходимо обращаться к свойству count.value.
  • Автоматическая распаковка в <template>: Внутри HTML-шаблона писать .value не нужно. Vue автоматически извлекает значение при рендере: <p>Счетчик: {{ count }}</p> <!-- Правильно -->
  • Идеально для примитивов: ref() применяется для хранения чисел (как count), строк, логических значений (boolean), null и undefined.
  • Передача в шаблон: Чтобы переменная count и функция increment были доступны в разметке <template>, их нужно вернуть в объекте return { count, increment }.
