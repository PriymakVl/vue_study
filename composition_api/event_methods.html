Создание и вызов методов по событию

  • В Composition API методы объявляются как обычные JavaScript-функции внутри блока setup().
  • Для привязки метода к DOM-событию в шаблоне используется директива v-on: или её сокращённая запись @ (например, @click).
  • Чтобы метод стал доступен в разметке <template>, его необходимо вернуть в объекте из функции setup(). 
<!-- CounterComponent.vue -->
<template>
  <div class="p-4">
    <p>Счетчик: {{ count }}</p>
    <!-- Привязка метода increment к событию клика -->
    <button @click="increment">Увеличить</button>
  </div>
</template>

<script>
import { ref } from 'vue';

export default {
  name: 'CounterComponent',
  setup() {
    const count = ref(0);

    // 1. Объявление метода внутри setup()
    const increment = () => {
      console.log('Текущее значение:', count.value);
      count.value++;
    };

    // 2. Возврат метода для использования в шаблоне
    return {
      count,
      increment
    };
  }
}
</script>

Как работать с методами и событиями:

  • Объявление функции: Внутри setup() можно использовать как стрелочные функции (const increment = () => { ... }), так и классическое объявление (function increment() { ... }). Ключевое слово this при этом не используется.
  • Экспорт в шаблон через return: Любая функция, созданная в setup(), остаётся локальной, пока вы не укажете её в return { increment }. Без этого шаблон не сможет её вызвать.
  • Подписка на событие в <template>: Символ @ заменяет директиву v-on:. Запись @click="increment" указывает Vue выполнить функцию increment при нажатии на кнопку: <button @click="increment">Увеличить</button> <!-- Эквивалентно v-on:click="increment" -->
  • Передача имени метода без скобок: При стандартном вызове обработчика скобки не ставятся (@click="increment"). В этом случае Vue автоматически передаёт первым аргументом нативный объект события (Event), если он понадобится внутри функции.
  • Передача аргументов в метод: Если методу нужны собственные параметры, его вызывают со скобками в шаблоне — например, @click="incrementBy(5)". Если при этом нужен и объект события, его передают через специальную переменную $event: @click="incrementBy(5, $event)".
