Vue.js Composition API — Функция setup()
1

Назначение и возврат данных из setup()

  1. Функция setup() — это главная точка входа для использования Composition API внутри компонента Vue.
  2. В ней группируется логика компонента: объявление данных, вспомогательных переменных, функций и обработчиков событий.
  3. Любые переменные и функции, объявленные внутри setup(), остаются локальными и доступны в шаблоне <template> только после явного возврата в виде свойств объекта return { ... }. 
<!-- UserCard.vue -->
<template>
  <div class="card">
    <h3>{{ title }}</h3>
    <p>Роль: {{ role }}</p>
    <button @click="logInfo">Показать в консоли</button>
  </div>
</template>

<script>
export default {
  name: 'UserCard',
  setup() {
    // 1. Локальная переменная (не передается в шаблон)
    const secretCode = 'ID-9482';

    // 2. Данные для отображения в шаблоне
    const title = 'Профиль разработчика';
    const role = 'Frontend Engineer';

    // 3. Метод-обработчик
    const logInfo = () => {
      console.log(`Карточка: ${title}, внутренний код: ${secretCode}`);
    };

    // 4. Возвращаем только то, что нужно шаблону
    return {
      title,
      role,
      logInfo
    };
  }
}
</script>
  1. Инкапсуляция логики — переменная secretCode не включена в return, поэтому она доступна внутри функции logInfo, но скрыта от шаблона.
  2. return { title, role, logInfo } — формирует публичный интерфейс компонента для <template> и других опций компонента.
