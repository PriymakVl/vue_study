Vue.js Composition API — Синтаксис <script setup>
1

Использование <script setup> в однофайловых компонентах

  • Атрибут <script setup> — это синтаксический сахар для использования Composition API внутри однофайловых компонентов (SFC) во Vue 3.
  • Он избавляет от необходимости писать обёртку export default { setup() { ... } } и вручную возвращать данные через return.
  • Все переменные верхнего уровня, функции и импорты внутри <script setup> автоматически становятся доступны в разметке <template>. 
<!-- CounterComponent.vue -->
<template>
  <div class="p-4">
    <p>Счетчик: {{ count }}</p>
    <!-- Переменная count и метод increment доступны напрямую -->
    <button @click="increment">Увеличить</button>
  </div>
</template>

<script setup>
import { ref } from 'vue';

// 1. Объявление реактивного состояния на верхнем уровне
const count = ref(0);

// 2. Объявление метода (возвращать через return больше не нужно)
const increment = () => {
  console.log('Текущее значение:', count.value);
  count.value++;
};
</script>

Ключевые преимущества и особенности <script setup>:

  • Автоматический экспорт в шаблон: Любая переменная (const count = ref(0)) или функция (increment), объявленная на верхнем уровне блока <script setup>, сразу видна в <template> без громоздкого объекта return { count, increment }.
  • Меньше шаблонного кода: Код внутри <script setup> компилируется непосредственно в тело функции setup() компонента, что делает запись компактнее и читаемее.
  • Прямая регистрация импортов: Импортированные дочерние компоненты или вспомогательные функции сразу доступны в шаблоне. Регистрировать компоненты в секции components: {} не требуется: <script setup> import CustomButton from './CustomButton.vue'; // Сразу можно использовать <CustomButton /> в template </script>
  • Изоляция для каждого экземпляра: В отличие от обычного <script>, который выполняется один раз при импорте модуля, код внутри <script setup> выполняется заново при создании каждого экземпляра компонента.
  • Макросы компилятора: Для объявления входных параметров и событий внутри <script setup> используются встроенные макросы defineProps() и defineEmits(), которые не нужно импортировать.
