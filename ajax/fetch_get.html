Vue.js Composition API — Получение данных (GET) через fetch()
1

Получение данных (GET) и передача в дочерний компонент

  1. Для работы с асинхронными запросами в <script setup> используются реактивные переменные ref() для хранения данных, состояния загрузки (isLoading) и текста ошибки (error).
  2. Чтобы загрузить данные автоматически при открытии страницы, вызов функции с fetch() помещают внутрь хука жизненного цикла onMounted().
  3. Метод fetch() не считает HTTP-ошибки (например, 404 или 500) исключением, поэтому статус ответа проверяют вручную через response.ok. 
<!-- src/App.vue -->
<template>
  <div class="container">
    <h2>Список пользователей</h2>
    <button @click="loadUsers" :disabled="isLoading">Обновить</button>

    <p v-if="isLoading">Загрузка данных...</p>
    <p v-else-if="error" class="error">Ошибка: {{ error }}</p>

    <div v-else class="grid">
      <UserItem
        v-for="user in users"
        :key="user.id"
        :user="user"
      />
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue';
import UserItem from './components/UserItem.vue';

const users = ref([]);
const isLoading = ref(false);
const error = ref(null);

const loadUsers = async () => {
  isLoading.value = true;
  error.value = null;

  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/users');
    if (!response.ok) {
      throw new Error(`HTTP ошибка: ${response.status}`);
    }
    users.value = await response.json();
  } catch (err) {
    error.value = err.message;
  } finally {
    isLoading.value = false;
  }
};

onMounted(() => {
  loadUsers();
});
</script>
<!-- src/components/UserItem.vue -->
<template>
  <div class="user-card">
    <h3>{{ user.name }}</h3>
    <p>Email: {{ user.email }}</p>
    <p>Город: {{ user.address.city }}</p>
  </div>
</template>

<script setup>
defineProps({
  user: {
    type: Object,
    required: true
  }
});
</script>
  1. try / catch / finally — блок finally гарантированно выключает индикатор isLoading как при успешном ответе, так и при обрыве сети.
  2. Компонентный подход — родительский компонент App.vue отвечает за загрузку данных, а дочерний UserItem.vue получает готовый объект через defineProps и отвечает только за отображение.
