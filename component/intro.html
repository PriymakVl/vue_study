Vue.js — Компоненты
1

Что такое компонент?

Компонент — это модуль (самостоятельная часть сайта). Компоненты позволяют разделить сложный интерфейс на небольшие, легко управляемые и изолированные части.

Основные особенности:

  • Создаются в отдельных файлах с расширением .vue.
  • Могут переиспользоваться в разных местах проекта.
  • Могут встраиваться друг в друга (имеют вложенность «родитель — ребёнок»).
2

Структура Single File Component (SFC)

Каждый .vue файл объединяет в себе три части:

<template>
Собственная разметка и структура компонента.
<script>
Логика и поведение компонента.
<style>
Стили оформления.
<!-- components/MyButton.vue -->
<template>
  <button class="btn" @click="handleClick">
    <slot>Нажми меня</slot>
  </button>
</template>

<script setup>
const handleClick = () => {
  console.log('Кнопка нажата!');
};
</script>

<style scoped>
.btn {
  background-color: #42b883;
  color: white;
  padding: 8px 16px;
  border-radius: 6px;
}
</style>
3

Односторонний поток данных

Vue придерживается концепции одностороннего потока данных (One-Way Data Flow), что делает состояние приложения предсказуемым и легко контролируемым.

Parent (Родитель)
props → (входные параметры) ← → ← emit (события)
Child (Дочерний)
  • props — передача данных от родительского компонента к дочернему.
  • events / emit — отправка событий и данных от дочернего компонента к родительскому.
4

Типы компонентов и структура проекта

Виды компонентов:

  • Локальные: используются только внутри конкретного компонента.
  • Глобальные: регистрируются один раз при старте приложения и доступны повсеместно.

Примеры компонентов:

Кнопка Меню Карточка товара Комментарий

Структура папок приложения:

Обычно компоненты хранятся в директории src/components/:

project/
├── src/
│   ├── components/
│   │   └── MyButton.vue
│   ├── App.vue
│   └── main.js
