Применение v-model для компонентов

Во Vue 3 можно использовать директиву v-model для собственных компонентов. Это позволяет организовать двустороннюю передачу данных между родительским и дочерним компонентами.

1

Родительский компонент (App.vue)

<script>
import MyInput from './MyInput.vue'

export default {
  components: {
    MyInput
  },
  data() {
    return {
      message: 'Привет'
    }
  }
}
</script>

<template>
  <MyInput v-model="message" />
  <p>{{ message }}</p>
</template>
2

Дочерний компонент (MyInput.vue)

<script>
export default {
  props: ['modelValue'],
  emits: ['update:modelValue']
}
</script>

<template>
  <input
    :value="modelValue"
    @input="$emit('update:modelValue', $event.target.value)"
  >
</template>
3

Как это работает?

Запись <MyInput v-model="message" /> преобразуется компилятором Vue примерно в следующий код: 

<MyInput
  :modelValue="message"
  @update:modelValue="message = $event"
/>
  • modelValue — передаёт текущее значение из родительского компонента в дочерний через пропс.
  • update:modelValue — эмитирует событие с новым значением обратно родителю при изменении ввода.
  • Реактивное обновление — родительский компонент перехватывает событие и автоматически обновляет свою переменную message.
4

Можно ли использовать несколько v-model?

Да, Vue 3 поддерживает привязку нескольких v-model к одному компоненту с помощью именованных аргументов: 

<UserForm
  v-model:name="userName"
  v-model:age="userAge"
/>

В дочернем компоненте используются соответствующие пропсы и события:

  • Пропс name и событие update:name.
  • Пропс age и событие update:age.
Главный вывод: v-model на пользовательском компоненте — это удобная синтаксическая обёртка над комбинацией props и emit, обеспечивающая полноценную двустороннюю связь.
