Vue.js - Использование Emit в Options API
1

Дочерний компонент (ChildComponent.vue)

Дочерний компонент генерирует пользовательское событие при помощи встроенного метода this.$emit и передаёт данные родительскому компоненту. 

<!-- ChildComponent.vue -->
<template>
  <div class="child">
    <button @click="sendNotification">
      Отправить данные родителю
    </button>
  </div>
</template>

<script>
export default {
  emits: ['custom-event'], // Явное объявление события
  methods: {
    sendNotification() {
      // Генерируем событие 'custom-event' и передаём объект данных
      this.$emit('custom-event', {
        id: 42,
        message: 'Данные успешно отправлены из дочернего компонента!'
      });
    }
  }
}
</script>
  • emits: ['custom-event'] — опция для явного объявления пользовательских событий, генерируемых компонентом. Это улучшает документирование кода и самопроверку фреймворка.
  • this.$emit('custom-event', payload) — системный метод Vue:
    • Первый параметр ('custom-event') — уникальное имя события, которое будет отлавливать родитель.
    • Второй параметр ({ id: 42, message: '...' }) — полезная нагрузка (payload), любые данные, передаваемые вверх по цепочке компонентов.
2

Родительский компонент (ParentComponent.vue)

Родительский компонент подписывается на кастомные события дочернего элемента, извлекает полученные данные и обновляет свое внутреннее состояние. 

<!-- ParentComponent.vue -->
<template>
  <div class="parent">
    <!-- Подписываемся на событие @custom-event -->
    <ChildComponent @custom-event="handleCustomEvent" />
    
    <!-- Отображаем сообщение при его наличии -->
    <p v-if="receivedMessage" class="message">
      {{ receivedMessage }}
    </p>
  </div>
</template>

<script>
import ChildComponent from './ChildComponent.vue';

export default {
  components: {
    ChildComponent
  },
  data() {
    return {
      receivedMessage: ''
    }
  },
  methods: {
    handleCustomEvent(payload) {
      // payload содержит объект, переданный из this.$emit
      this.receivedMessage = payload.message;
    }
  }
}
</script>
  • <ChildComponent @custom-event="handleCustomEvent" /> — вставка дочернего компонента в шаблон. Символ @custom-event подписывает родителя на событие дочернего элемента и при его наступлении автоматически вызывает метод handleCustomEvent.
  • handleCustomEvent(payload) — метод-обработчик. Аргумент payload автоматически получает данные, переданные с помощью this.$emit.
