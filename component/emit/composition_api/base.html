Vue.js - Использование Emit в Composition API
1

Дочерний компонент (ChildComponent.vue)

В Composition API при использовании синтаксиса <script setup> функция emit создаётся с помощью компилируемого макроса defineEmits(). 

<!-- ChildComponent.vue -->
<template>
  <div class="child">
    <button @click="sendNotification">
      Отправить данные родителю
    </button>
  </div>
</template>

<script setup>
// Объявляем возможные события с помощью макроса defineEmits
const emit = defineEmits(['custom-event']);

const sendNotification = () => {
  // Генерируем событие 'custom-event' и передаём данные
  emit('custom-event', {
    id: 42,
    message: 'Данные успешно отправлены из дочернего компонента!'
  });
};
</script>
  • defineEmits(['custom-event']) — макрос компилятора (не требует импорта), объявляющий список эмитируемых событий. Возвращает эквивалент функции $emit.
  • emit('custom-event', payload) — вызванная функция генерирует событие:
    • Первый параметр ('custom-event') — имя события для отслеживания родителем.
    • Второй параметр ({ id: 42, message: '...' }) — объект или значение полезной нагрузки (payload).
2

Родительский компонент (ParentComponent.vue)

Родительский компонент подключает дочерний через импорт, отслеживает событие с помощью directive @custom-event и сохраняет переданные данные в реактивную переменную ref. 

<!-- ParentComponent.vue -->
<template>
  <div class="parent">
    <!-- Подписываемся на событие @custom-event -->
    <ChildComponent @custom-event="handleCustomEvent" />
    
    <!-- Отображаем сообщение при его наличии -->
    <p v-if="receivedMessage" class="message">
      {{ receivedMessage }}
    </p>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import ChildComponent from './ChildComponent.vue';

const receivedMessage = ref('');

const handleCustomEvent = (payload) => {
  // payload содержит объект, переданный из функции emit
  receivedMessage.value = payload.message;
};
</script>
  • import ChildComponent ... — в синтаксисе <script setup> импортированные компоненты автоматически становятся доступными в шаблоне без явной регистрации.
  • receivedMessage.value = payload.message — реактивная ссылка извлекается и изменяется через свое свойство .value внутри скрипта.
