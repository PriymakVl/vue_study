Использование Emit в Options API

Генерация событий (emit) позволяет дочернему компоненту отправлять сообщения и передавать данные снизу вверх — обратно родительскому компоненту.

1

Отправка событий из дочернего компонента

В Options API отправка пользовательского события выполняется через экземпляр метода this.$emit('eventName', payload). Первый аргумент определяет название события, а последующие — передаваемые данные: 

<!-- ChildComponent.vue -->
<template>
  <div class="child">
    <button @click="sendNotification">
      Отправить данные родителю
    </button>
  </div>
</template>

<script>
export default {
  methods: {
    sendNotification() {
      // Генерируем событие 'custom-event' и передаём объект данных
      this.$emit('custom-event', {
        id: 42,
        message: 'Данные успешно отправлены из дочернего компонента!'
      });
    }
  }
}
</script>
2

Прослушивание событий родительским компонентом

Родительский компонент отлавливает пользовательские события дочернего элемента с помощью директивы v-on или ее сокращения @: 

<!-- ParentComponent.vue -->
<template>
  <div class="parent">
    <!-- Подписываемся на пользовательское событие @custom-event -->
    <ChildComponent @custom-event="handleCustomEvent" />
    <p v-if="receivedMessage">{{ receivedMessage }}</p>
  </div>
</template>

<script>
import ChildComponent from './ChildComponent.vue';

export default {
  components: {
    ChildComponent
  },
  data() {
    return {
      receivedMessage: ''
    }
  },
  methods: {
    handleCustomEvent(payload) {
      // Аргумент payload содержит переданный из $emit объект
      this.receivedMessage = payload.message;
    }
  }
}
</script>
3

Объявление и валидация опции emits (Рекомендуется)

Во Vue 3 рекомендуется явно декларировать эмитируемые события в опции emits. Это не только служебная документация компонента, но и возможность валидировать передаваемые данные.

Массив событий

Простая декларация имён генерируемых событий: emits: ['close', 'submit'].

Валидация

Определение функции валидации для проверки аргументов, передаваемых вместе с событием.

Результат

Возврат false в функции валидации выведет предупреждение в консоли разработчика. 

<!-- ChildComponent.vue -->
<script>
export default {
  // Декларация и валидация генерируемых событий
  emits: {
    // Событие без валидации
    close: null,

    // Событие с валидацией аргументов
    submit: ({ email, password }) => {
      if (email && password) {
        return true; // Валидация пройдена
      } else {
        console.warn('Ошибка: Для события submit обязательны email и password!');
        return false; // Появится предупреждение в консоли
      }
    }
  },
  methods: {
    submitForm() {
      this.$emit('submit', { 
        email: 'user@example.com', 
        password: 'secret_password' 
      });
    }
  }
}
</script>

Важные особенности Options API Emit:

  • События обеспечивают обратный поток данных (снизу вверх), сохраняя концепцию однонаправленного потока данных в архитектуре Vue.
  • Рекомендуется называть события в формате kebab-case (например, update-user) для единообразия с синтаксисом HTML-шаблонов.
  • Явное объявление в опции emits предотвращает попадание событий в качестве обычных атрибутов ($attrs) на корневой элемент компонента.
