Использование Props в Options API

Пропсы (Props) — это пользовательские атрибуты, которые можно зарегистрировать в компоненте для передачи данных от родительского компонента к дочернему.

1

Передача данных от родителя

Родительский компонент передаёт данные в дочерний через динамический атрибут, используя директиву v-bind (или её сокращение :): 

<!-- ParentComponent.vue -->
<template>
  <div class="parent">
    <!-- Передаём значение postTitle в проп :title -->
    <ChildComponent :title="postTitle" />
  </div>
</template>

<script>
import ChildComponent from './ChildComponent.vue';

export default {
  components: {
    ChildComponent
  },
  data() {
    return {
      postTitle: 'Изучение Vue.js Props в Options API'
    }
  }
}
</script>
2

Приём props в дочернем компоненте (Базовый вариант)

В Options API пропсы объявляются в опции props объекта компонента. В самом простом виде пропсы можно передать массивом или объектом с указанием типов: 

<!-- ChildComponent.vue -->
<template>
  <h1>{{ title }}</h1>
</template>

<script>
export default {
  // Простая регистрация входного параметра
  props: {
    title: String
  }
}
</script>
3

Типизированный вариант (Рекомендуется)

Для более надежной валидации данных рекомендуется подробно описывать схему каждого входного параметра компонента с указанием типа, обязательности и дефолтных значений.

type

Определяет ожидаемый тип данных (напр. String, Number, Boolean, Array, Object).

required

Указывает, является ли prop обязательным. Значение required: true выведет предупреждение в консоль, если параметр не передан.

default

Задаёт значение по умолчанию, если prop не был передан из родителя. 

<!-- ChildComponent.vue -->
<template>
  <div class="card">
    <h1>{{ title }}</h1>
  </div>
</template>

<script>
export default {
  // Подробная (типизированная) схема входного параметра
  props: {
    title: {
      type: String,
      required: true,
      default: ''
    }
  }
}
</script>

Важные особенности Options API Props:

  • Все пропсы формируют однонаправленный поток данных (One-Way Data Flow): дочерний компонент не должен изменять переданные ему пропсы напрямую.
  • Внутри методов и computed-свойств компонента доступ к пропсам осуществляется через this.title.
  • Для объектов и массивов значение по умолчанию (default) должно возвращаться из функции, например: default: () => ([]).
