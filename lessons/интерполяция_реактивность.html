Інтерполяція та Реактивність у Vue.js

1. Інтерполяція

Інтерполяція — це спосіб виведення даних із Vue в HTML-шаблон за допомогою подвійних дужок {{ }}.

Як це працює:
  • У HTML ми записуємо назву змінної у дужках: {{ message }}.
  • Значення змінної створюється та задається в блоці data().
  • Vue автоматично підставляє значення цієї змінної замість дужок на сторінці.
  • Будь-яка зміна значення змінної одразу оновлює текст на екрані.

2. Реактивність

Реактивність — це автоматичне оновлення сторінки при зміні значення змінної.

Як це працює:
  • Змінні, оголошені в data(), стають реактивними.
  • При зміні такої змінної Vue автоматично перемальовує тільки потрібну частину сторінки.
  • Без реактивності нам довелося б вручну шукати елемент через JavaScript і змінювати його текст (наприклад, через document.querySelector).
