1. Створення та оголошення змінних у Vue (Options API)

У Vue.js (при використанні підходу Options API) всі реактивні змінні описуються всередині спеціальної функції data(), яка повертає об'єкт зі значеннями.

<div id="app">
  <p>{{ message }}</p>
</div>

<script>
  const app = Vue.createApp({
    data() {
      return {
        message: 'Привіт'
      }
    }
  })
  
  app.mount('#app')
</script>
Пояснення: Функція data() обов'язково повинна повертати об'єкт через return { ... }. Всі ключі цього об'єкта (наприклад, message) стають реактивними змінними, до яких можна звертатися в шаблоні HTML.

2. Важливі синтаксичні правила та розбір помилок

Під час оголошення даних у Vue важливо дотримуватися правильного синтаксису JavaScript об'єктів:

ЕлементОпис правилаПриклад
Функція data()Повертає об'єкт return { ... } з даними.data() { return { ... } }
Розділювач парУсередині об'єкта ключі й значення розділяються двокрапкою :.title: 'Vue'
Коми між ключамиВсі поля об'єкта відокремлюються комами ,.name: 'Іван', age: 20
Монтування mount()Прив'язує екземпляр Vue до HTML-елемента за його CSS-селектором.app.mount('#app')

Типові помилки початківців:

  1. Забутий return: Якщо у data() не повернути об'єкт, Vue не побачить ваші змінні.
  2. Синтаксичні дужки: Закриття data() або return не у тому місці викликає синтаксичну помилку SyntaxError.
  3. Забуте монтування: Якщо не викликати app.mount('#app'), шаблон `{{ message }}` так і залишиться незмінним текстом на сторінці.
Інтерактивна перевірка імені змінної у Vue. Введіть назву змінної, щоб дізнатися, чи вона правильна для об'єкта data():

3. Відображення змінних у шаблоні (Mustache / Інтерполяція)

Для того щоб вивести значення змінної в HTML-код, використовуються подвійні фігурні дужки {{ }} (їх часто називають "вусами" або Mustache-синтаксисом).

<div id="app">
  <h1>Товар: {{ product }}</h1>
  <p>Ціна: {{ price }} грн</p>
  <p>Загалом з урахуванням знижки: {{ price - 100 }} грн</p>
</div>
Зверніть увагу: Усередині {{ }} можна виконувати найпростіші математичні обчислення або операції з рядками (наприклад, {{ price * count }} або {{ message.toUpperCase() }}).

4. Практичні завдання

Завдання 1. Пошук синтаксичної помилки. Знайдіть помилку в наступному коді оголошення Vue-додатку: 
data() {
  return {
  })
}
message: 'Привіт'
Перевірити відповідь

Помилка: Фігурна дужка та дужка }) закривають об'єкт і функцію занадто рано, до того як оголошено поле message!

Правильний варіант:

data() {
  return {
    message: 'Привіт'
  }
}
Завдання 2. Додавання кількох змінних. Додайте до об'єкта data() дві змінні: product зі значенням 'Телефон' та price зі значенням 15000.
Показати код Vue 
const app = Vue.createApp({
  data() {
    return {
      product: 'Телефон',
      price: 15000
    }
  }
})
app.mount('#app')
