Змінні у Vue.js (Options API)

1. Створення та ініціалізація змінної у Vue.js

У Vue.js (Options API) всі реактивні змінні створюються всередині спеціальної функції data(), яка повертає об'єкт із даними додатка.

<div id="app">
  <p>{{ message }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const app = Vue.createApp({
    data() {
      return {
        message: 'Привіт!'
      }
    }
  });

  app.mount('#app');
</script>
Пояснення з опису матеріалів:
  • Функція data() повертає об'єкт.
  • Кожна властивість цього об'єкта (наприклад, message) стає реактивною змінною, яку можна використовувати в HTML-шаблоні через підстановку {{ message }}.
  • Обов'язково викликається app.mount('#app') для зв'язування Vue з елементом DOM.
